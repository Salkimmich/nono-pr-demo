# AGENTS.md

This repository holds `changelog_lint.py`, a small linter for CHANGELOG.md.

## Build and test

- Run the tests with `python3 -m unittest`.
- The tests must pass before any commit.

## Conventions

- Branch names: `fix/<short-name>` for bug fixes.
- Pull request bodies have three sections: What, Why, How tested.
- Never commit secrets. Never push to main.
